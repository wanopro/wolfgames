# 🐺 울프 게임즈 (Wolf Games)

술자리에서 폰 하나로 바로 하는 게임 모음 안드로이드 앱입니다.
Powered by WOLF(feat. segna) · https://wolf.community

## 📖 설치 안내 (그림 포함 · 6개 언어)

**https://wanopro.github.io/wolfgames/manual.html**
안드로이드 APK 설치(보안 허용)와 아이폰 홈 화면 추가 방법, **게임 27종 + N빵·팁·환전·연락처 QR·숙소 주소 카드·두 언어 보기 사용법**을 실제 화면과 함께 정리했습니다. 페이지 위쪽에서 언어를 고르면 설명과 그림이 그 언어로 바뀝니다.

- 최신 APK 고정 링크: https://github.com/wanopro/wolfgames/releases/latest/download/WolfGames.apk
- 현재 버전: **v1.6**

## 🌐 웹 버전 (아이폰 · PC)

**https://wanopro.github.io/wolfgames/**

- 아이폰: 사파리로 열고 **공유 → 홈 화면에 추가**를 누르면 늑대 아이콘이 생기고, 앱처럼 전체 화면으로 열립니다.
- 한 번 열어두면 인터넷이 약해도 실행됩니다(오프라인 지원).
- 게임, 언어, 화면은 안드로이드 앱과 같습니다.
- 아이폰 사파리는 웹 진동을 지원하지 않아서 진동은 나오지 않아요. 안드로이드 크롬에서는 진동이 됩니다.
- `web/` 폴더가 바뀌면 GitHub Actions가 자동으로 다시 배포합니다.

## 📥 안드로이드 앱 설치

1. 폰에서 이 저장소의 **Releases** 메뉴를 열고 가장 최신 `WolfGames.apk`를 받습니다.
2. 설치할 때 "출처를 알 수 없는 앱 허용"을 한 번 켜줍니다.
3. 새 버전은 기존 앱을 지우지 않고 그대로 덮어 설치하면 됩니다.

코드가 바뀌어 올라올 때마다 GitHub Actions가 새 APK를 자동으로 만들어 Releases에 올립니다.

## 🎮 게임 목록

### 🎲 주사위

**주사위 굴리기**
- 여러 명이 동시에 화면에 손가락을 올립니다. 손가락마다 다른 색 원이 생겨요.
- 원 둘레의 진행 링이 0.5초 동안 차오르고, 다 차면 진동이 옵니다. 그때 손을 떼면 그 자리에 주사위가 나와요.
- 0.5초 전에 떼면 주사위가 나오지 않습니다.
- 주사위가 2개 이상 나오면 **제일 높은 수(👑 최고, 금색으로 반짝)** 와 **제일 낮은 수(💀 최저, 빨갛게 덜덜)** 가 눈에 확 띄어요. 나머지는 흐려지고, 전부 같은 수면 강조하지 않아요.
- 화면을 더블탭하거나 위쪽 "초기화"를 누르면 리셋됩니다.

**숫자 뒤집기 잭팟** (태국 야시장 보드게임)
- 1~12 숫자판과 주사위 2개로 하고, 참가 인원은 1~8명입니다.
- 주사위를 던지면 두 눈과 그 합이 켜집니다. 예를 들어 1·4가 나오면 1, 4, 5가 켜져요.
- **합(5)을 고르면** 5만 뒤집고 차례가 끝납니다.
- **눈 하나(1)를 고르면** 나머지 눈(4)만 켜져서 이어서 뒤집을 수 있어요. "여기서 마치기"를 누르면 하나만 뒤집고 끝낼 수도 있습니다.
- 뒤집을 숫자가 없으면 다음 사람 차례입니다.
- **마지막 숫자를 뒤집은 사람이 승리**합니다.

**5개 주사위** (2~4명)
- 폰을 테이블 가운데에 놓으면 각자 자기 방향으로 보이도록 화면이 나뉩니다.
- 각자 주사위 5개로 시작하고, **자기 영역을 탭하면** 자기 주사위만 굴러갑니다.
- 모든 사람이 다 굴리면 결과가 한꺼번에 반영돼요.
  - 1이 나온 주사위는 아웃
  - 6이 나온 주사위는 시계방향으로 아직 남아 있는 옆 사람에게
- 주사위가 하나도 남지 않으면 **탈출**하고, 나머지 사람끼리 계속합니다.
- **마지막까지 주사위가 남은 한 명이 패배**하는, 패자 정하기 게임이에요. 마지막 남은 사람들이 같은 판에 동시에 0개가 되면 그 사람들이 공동 패배예요.

**789** (2~8명)
- 차례대로 화면을 탭하면 주사위 2개가 통통 튀며 굴러가고, **두 눈 합의 뒷자리**로 정해집니다.
  - 7 → **첨잔**, 8 → **반만 마시기**, 9 → **한번에 다 마시기**
  - 6 → **순서 반대로** (설정에서 켜고 끌 수 있음)
  - 나머지(합 10~12 포함) → 통과, 다음 사람
- 위쪽에 지금 차례인 플레이어와 진행 방향(↻/↺)이 표시돼요.

**⚔️ 주사위 대결** (2~4명)
- 주사위 개수(2~4개)와 계산 방법(**더하기 / 곱하기**)을 정합니다.
- 폰을 가운데 두면 화면이 원형으로 같은 크기로 나뉘고, 각자 자기 영역을 탭하면 주사위가 굴러가요.
- 모두 굴리면 **👑 최고**와 **💀 최저**가 표시돼요. 같은 값이면 같이 표시, 전부 같으면 표시 안 함. 가운데 원을 누르면 다시 해요.

### 🃏 카드

**Up/Down** (2~8명)
- 바닥 카드보다 다음 카드가 높을지(**UP**) 낮을지(**DOWN**) 맞힙니다. A(가장 낮음) < 2 … 10 < J < Q < K(가장 높음)
- 기준 카드가 A나 K면 **레드/블랙**을 맞혀요.
- 맞히면 다음 사람 차례, 틀리면 벌주 후 새 카드로 다시 시작. **같은 숫자가 나오면 원샷**!
- **누적 옵션**: 맞힐 때마다 벌주가 1잔씩 쌓이고, 틀린 사람이 쌓인 잔을 다 마셔요.
- 조커 없는 52장, 카드가 떨어지면 자동으로 다시 섞어요.

**호치민** (2~4명)
- 각자 카드 1장을 받아 자기 숫자로 정해요. (A=1, 10·J·Q·K = 0)
- 가운데에 카드 2장이 펼쳐져 있고, 차례인 사람이 바꿀 카드 1장을 누르면 새 카드가 뒤집혀 올라와요.
- **두 카드 합의 뒷자리가 내 숫자면 원샷**! 여러 명이 걸리면 다 같이 마셔요.
- 5개 주사위처럼 폰을 테이블 가운데에 두면 각자 방향으로 보여요. **새 게임**으로 카드를 다시 나눠요.

**👑 글로벌 킹스컵**
- 호스텔·펍에서 많이 하는 King's Cup을 **그림으로** 옮겼어요. 영어 몰라도 카드 한가운데 큰 그림만 보면 돼요.
- 카드 더미를 터치하면 한 장씩 뒤집혀 나와요.
  - A 🌊 폭포 · 2 👉 지목 · 3 🙋 나 · 4 🚽 화장실 프리패스 · 5 💃 댄스 릴레이 · 6 🍻 다 같이 짠 · 7 🙌 하늘 · 8 🤝 짝꿍 · 9 🔤 끝말잇기 · 10 📚 카테고리 · J 📜 규칙 만들기 · Q ❓ 질문 마스터 · K 👑 킹스컵
- K가 나올 때마다 오른쪽 위 킹스컵 잔이 1/4씩 차오르고, **4번째 K를 뽑은 사람이 킹스컵 원샷**!
- **📋 규칙 보기**로 언제든 확인, **🔀 새로 섞기**로 새 판. 남은 카드 수도 보여요.

### 👆 손가락게임

**☝️ 손가락선택**
- 걸릴 인원(1~9명)을 먼저 정합니다.
- 다 같이 화면에 손가락을 하나씩 올리면 손가락마다 다른 색 원이 생겨요.
- **모든 손가락이 떨어지고 0.5초가 지나면** 결과가 나와요. 그 전까지는 늦게 올리는 사람도 같이 들어가요.
- 걸린 사람 자리에만 늑대가 튀어나와 **메롱~** 하고 혀를 날름거리며 약올리고, 나머지는 "통과"로 흐려져요.
- 참가한 손가락이 걸릴 인원보다 많아야 해요. 화면을 탭하면 다시 합니다.

### ⚡ 순발력게임

세 게임 모두 폰을 가운데 두면 화면이 **원형으로 같은 넓이**만큼 나뉘어요(2명은 위아래, 3명은 Y자, 4명은 X자). 글자는 각자 앉은 쪽을 향해 있고, 가운데 원을 누르면 다시 합니다.

**🟢 반응속도 대결** (2~4명)
- "기다리세요..." 화면이 랜덤한 때에 **초록색으로 바뀌는 순간** 자기 영역을 터치!
- 각자 반응 시간(0.000초)이 나오고 **👑 1등 · 💀 꼴찌**가 금색·빨간 테두리로 표시돼요.
- 초록 되기 전에 누르면 **🚫 부정출발**(꼴찌 처리).

**🎨 색 반응 대결** (2~4명)
- 가운데 원에 이번 판 **지정색**(빨강·주황·노랑·초록·파랑·보라 중 랜덤)이 나와요.
- 화면 전체가 같은 색으로 **0.1~0.5초마다 랜덤하게** 바뀌다가 지정색이 나오면 터치!
- 지정색은 1.5초 동안 나와요. 그 안에 못 누르거나 다른 색에서 누르면 **💀 걸림**.
- 모두 눌렀으면 반응 시간과 등수, 1등·꼴찌 강조.

**⏱️ 스탑워치** (2~4명)
- 목표 시간(3~30초)을 정하면 가운데 원에 나와요. 3·2·1 뒤 시작하면 시간은 안 보여요.
- 속으로 세다가 됐다 싶을 때 터치 → 모두 끝나면 결과를 **소수점 둘째 자리**까지(예: 7.06초 / +0.06초)
- 목표에 가장 가까운 사람 **👑 1등**, 가장 먼 사람 **💀 꼴찌**.

**🍺 맥주 거품 채우기** (2~6명)
- 각자 자리에 맥주잔이 하나씩 있고, 모두 같은 속도로 맥주가 **빨라졌다 느려졌다 하면서** 차올라요(출렁이는 박자는 판마다 랜덤, 전체적으로는 갈수록 빨라짐).
- 빨간 점선 **"여기까지!"**에 맞춰 터치해서 멈추기 → 몇 %에서 멈췄는지 나와요.
- 선에 제일 가깝게 멈춘 사람 **👑 1등**, 선을 넘기면 **💦 넘쳤다 → 💀 꼴찌**.

### 🐺 늑대게임

**🐺 늑대이빨**
- 화면 가득 **늑대가 입을 쩍 벌리고**, 큰 이빨 20개가 넓게 나 있어요 (위 4 · 위턱 양옆 3+3 · 아래턱 양옆 3+3 · 아래 4). 이빨이 커서 네일을 해도 누르기 쉬워요.
- 이빨 중에 당첨 이빨이 숨어 있고, 당첨 개수는 1~10개로 정할 수 있습니다.
- 돌아가며 이빨을 하나씩 누르면 쏙 들어가요. 당첨을 누르면 입이 **콱 닫히면서 "앙!"** — 늑대가 눈을 질끈 감고 입을 꽉 다문 얼굴로 바뀌어요.
- 아래 빨간 **🔄**를 누르면 남은 당첨을 이어서 찾고, 모두 찾으면 다시 하기. **🔀 새로 섞기**로 언제든 새 판.

**🏁 늑대달리기**
- 참가 인원(2~9명)과 결과 시간(3~30초)을 정하고, **각자 동물을 골라요** (토끼·돼지·닭·양·사슴·쥐·오리·소·햄스터·병아리·강아지·고양이 12종, 누른 순서대로 레인 번호).
- 동물들은 **결승선 너머에서 덜덜 떨며** 기다리고, 귀여운 회색 늑대들이 다리를 움직이며 달려와요.
- 늑대마다 **폭풍 질주**(흙먼지·속도선)와 **주춤**하는 타이밍이 달라서 순위가 계속 엎치락뒤치락, 끝까지 접전이에요.
- 늑대가 가까워지면 동물은 겁먹고 땀을 흘리고, 늑대는 **입을 쩍 벌리고 물 준비**!
- 결승선에 오면 덮쳐서 **"앙!"** — **늑대가 먼저 문 동물이 1등**. 1등은 금색, 꼴찌는 빨강 배지예요.

**🗡️ 늑대 룰렛**
- 통에 칼 자리가 20개 있고, 그중 하나가 당첨입니다.
- 해적 두건을 쓴 늑대가 **통 안에 들어가** 앞발로 통을 붙잡고 내다보고 있어요.
- 돌아가며 칼 자리를 눌러 칼을 꽂아요. 통과하면 늑대가 쏙 올라와 한쪽 눈 찡긋, 혀를 날름거리며 **메롱~** 하고 약올려요.
- 당첨 자리에 꽂으면 **늑대가 빙글빙글 튀어나옵니다.**

**🔄 늑대 돌리기**
- 돌아가는 시간(1~15초)을 정하고 늑대를 탭하면, 늑대가 **입을 벌리고 빙글빙글 돌다가** 천천히 멈추면서 **"앙!" 하고 꽉 뭅니다.**
- 폰을 가운데에 두고, 늑대 입이 가리키는 사람이 당첨이에요. 꼬리는 등 쪽으로 동그랗게 말려 있어서 코끝이랑 헷갈리지 않아요.

### 🍀 운빨게임

**🪜 사다리게임**
- 참가 인원(2~10명)과 당첨 개수를 정합니다.
- 위쪽 번호를 누르면 선이 사다리를 타고 내려가서 결과가 공개돼요.
- 번호 하나를 누르든 "전체 결과"를 누르든 5초 동안 **귀여운 늑대 얼굴이 입을 앙앙 벌렸다 닫았다 하며** 사다리를 타고 내려가요. 목에 플레이어 색 목도리를 하고 있어요. "전체 결과"는 모든 줄이 동시에 내려가요.
- 도착하면 결과 칸 위에서 한 번 더 "앙!" 하고 쉬어요.

**🎡 돌림판**
- 총 칸 수(2~20칸)와 당첨 칸 개수를 정하면, 당첨 칸 위치는 무작위로 섞입니다.
- 탭하면 5초 동안 돌다가 천천히 멈춰요.

**💣 폭탄돌리기** (2~8명)
- 방향을 **시계방향 ↻ / 반시계방향 ↺ / 랜덤 🔀** 중에서 골라요. 화면은 원형으로 같은 넓이만큼 나뉘어요.
- **심지가 불꽃 튀며 타들어가는** 폭탄이 내 자리에 오면 터치! 정한 방향으로 폭탄이 날아가요.
- 터지는 시간은 10~30초 사이 랜덤(너무 짧게는 안 터져요).
- **펑!** 터지면 그 자리에 늑대가 튀어나와 콱콱 깨물고, 그 사람이 💀 당첨.

**🪙 동전 던지기** (2~8명)
- 화면이 원형으로 나뉘고, 각자 자리에서 **앞(🐺 귀여운 늑대 얼굴) / 뒤(🍑 늑대 엉덩이)**를 골라요.
- 모두 고르면 3·2·1 뒤 동전이 가운데서 튀어 올라 **빙글빙글 뒤집히다가** 떨어져요.
- 맞춘 사람 **⭕ 맞춤!(초록)**, 틀린 사람 **❌ 틀림!(빨강) 💀 원샷**.
- **15% 확률로 동전이 세로로 서서** 흔들흔들… → **전원 틀림!**

**🔻 플링코** (인원 상관없음, v1.6)
- 위쪽 아무 데나 터치하면 그 자리에서 **늑대 코인**이 떨어져 핀 사이를 톡톡 튕기다가 아래 칸에 쏙 들어가요.

### ⚔️ 대결게임

**🔴 4목**
- 2명이 빨강과 노랑으로 번갈아 하는 7×6 판 게임입니다. 알마다 **늑대 얼굴 무늬**가 들어 있어요.

- **가로·세로·대각선 중 하나로 4개를 먼저 이으면 승리**하고, 이긴 4칸이 반짝입니다. 판이 꽉 차면 무승부예요.
- 다음 판은 선공이 번갈아 바뀝니다.

**🎀 연타 땅따먹기** (2명, v1.5의 '탭 줄다리기')
- 폰을 사이에 두고 위·아래로 마주 앉아요. **GO!** 하면 내 쪽 화면을 미친 듯이 연타!
- 누를수록 가운데 깃발(🎀)이 상대 쪽으로 밀리고, 밀린 만큼 내 색이 상대 영역으로 번져요. 각자 탭 수도 나와요.
- 깃발을 **상대편 끝 점선**까지 밀면 승리 👑, 진 쪽엔 늑대가 튀어나와 앙! 💀 원샷.

**🐾 슬랩 대결** (2명, 손등 때리기 / Red Hands)
- 위·아래로 마주 앉으면 가운데에 **귀여운 늑대 앞발** 두 개가 겹쳐 있어요 (공격 발은 분홍 젤리 발바닥, 수비 발은 복슬 발등).
- **🛡️ 수비**: 내 쪽 화면을 손가락으로 **꾹 누르고 있다가**, 공격이 오면 떼서 피하기!
- **🐾 공격**: 아무 때나 내 쪽을 터치하면 찰싹! (0.22초 안에 수비가 떼면 회피)
- 맞으면 "짝!" + 발등이 빨개지고 **수비 원샷**(공격 계속) / 피하면 **공수 교대** / 공격이 안 왔는데 떼면 **움찔 반칙 🚫 원샷**.

**🟢 삼목** (2명, v1.6)
- 3×3 판에 **초록 vs 빨강 늑대 코인**을 번갈아 놓아요. 위·아래로 마주 앉고 (아래 = 초록, 위 = 빨강), 각자 쪽에 **"나: 초록"**처럼 내 색이 보여요.
- **한 수에 2초**. 시간을 넘기면 ⏰ 차례가 넘어가요.
- 코인은 **한 사람 3개까지** — 4번째를 놓으면 내 **가장 오래된 코인이 사라져요** (사라질 코인은 미리 깜빡여요).
- 가로·세로·대각선 3개를 먼저 이으면 승리, 진 사람 💀 원샷. 화면을 누르면 다음 판 (선공 번갈아).

**⚫ 오목** (2명, v1.6)
- 15×15 나무 바둑판, **흑이 먼저**. 위·아래로 마주 앉고 (아래 = 흑, 위 = 백), 각자 쪽에 **"나: 흑"**처럼 내 돌 색이 보이고 내 차례면 밝아져요.
- 시간 제한 없음. 빨간 점이 방금 둔 돌이에요.
- 가로·세로·대각선 5개를 먼저 이으면 승리, 진 사람 💀 원샷.
- 흑은 **🚫 33 금지**: 열린 3이 두 줄 동시에 생기는 자리에는 못 둬요 (5목이 되는 자리는 괜찮아요).

## 🧮 계산기 · N빵 · 팁 · 환전
- 메인 화면 로고 옆 **🧮 계산기** 버튼으로 엽니다. 아래 버튼은 **🍻 N빵 · 💁 팁 · 💱 환전** 순서예요.
- **🍻 N빵**: 계산기에 술값 총액을 넣고 누르면 인원수로 나눠 1인당 금액을 보여줘요. 100원 단위 올림처럼 올림 단위를 고를 수 있어요.
- **💁 팁**: **5 · 10 · 15 · 20 · 25 · 30%** 중 골라서 팁 금액과 팁 포함 합계를 보여줘요. 마지막에 고른 %를 기억하고, **🍻 팁 포함 N빵**으로 바로 나눌 수 있어요.
- **💱 환전**: 두 나라 통화를 고르면 환율로 바꿔줍니다. 환율은 하루 한 번 갱신되는 참고용이에요.

## 📇 내 연락처 QR
- 술자리 끝날 때 SNS 교환용. 메인 화면 로고 옆 **▦ QR** 버튼을 누르면 **흰 배경 풀화면 QR**이 떠서 상대가 폰 카메라로 바로 찍을 수 있어요.
- 처음 한 번만 쓰는 SNS를 입력: Instagram · WhatsApp(번호) · TikTok · LINE · 카카오톡(오픈프로필 링크) · Telegram · Facebook · Zalo(번호). 켜 둔 것만 나오고, 여러 개면 위 버튼이나 옆으로 넘겨서 바꿔요.
- 입력한 정보는 **이 휴대폰에만 저장**되고 어디로도 보내지 않아요. QR은 폰 안에서 만들어서 인터넷이 없어도 돼요.
- 안드로이드 앱은 QR을 띄우는 동안 화면을 최대 밝기로 올려요(웹은 밝기 조절 불가).

## 🏨 숙소 주소 카드
- 해외여행에서 택시 탈 때용. 메인 화면 **▦ QR** 옆 **🏨 숙소** 버튼을 누르면 **흰 화면에 큰 글씨**로 "여기로 가 주세요" + 숙소 이름 + 주소가 떠요 (메인 언어가 영어가 아니면 영어 한 줄도 같이).
- 주소는 예약 앱에서 **현지어 주소를 복사해서 붙여넣기**. 전화번호·메모(예: 편의점 옆 골목)는 선택.
- **📍 지도 QR**: 찍으면 구글 지도로 바로 길 안내. **📞 전화하기**: 숙소로 바로 전화.
- 숙소 여러 개 저장 가능 (위 버튼으로 바꾸기). 정보는 **이 휴대폰에만 저장**되고, QR은 폰 안에서 만들어서 인터넷이 없어도 돼요. 앱은 카드를 띄우는 동안 화면을 최대 밝기로 올려요.

## 🌐 두 언어 같이 보기
- 외국인 친구랑 할 때용. **🌐 언어** 화면에서 **2개까지** 고르면 처음 고른 게 **① 메인**, 두 번째가 **② 보조**예요. 누른 걸 다시 누르면 빠져요.
- 게임 설명부터 게임 화면·결과까지 메인 아래에 보조 언어가 **같은 글씨 크기로 살짝 흐리게** 같이 나와요.
- 메뉴, 화면 제목, 메인 화면 맨 위(앱 이름·버튼)는 메인 언어만 나와요 (두 언어면 너무 커져서).
- 게임 화면 속 글자는 두 줄이 원래 한 줄 자리에 들어가도록 같이 줄어들고, 버튼·칸은 글자만큼 늘어나서 겹치지 않아요.

## ⚙️ 기타 기능
- **💬 피드백**: 메인 화면 "술자리 게임 모음" 옆 링크를 누르면 [게시판 글](https://wolf.community/traveltalk/6817682)로 가요.
- **📜 업데이트 내역**: 메인 화면 맨 아래 `📜 v1.6 업데이트 내역`을 누르면 버전별 수정 사항이 6개 언어로 나와요. 새 버전을 처음 열면 바뀐 점을 한 번 띄워줍니다.
- **6개 언어**: 🇰🇷 한국어, 🇺🇸 English, 🇯🇵 日本語, 🇨🇳 简体中文, 🇹🇭 ไทย, 🇻🇳 Tiếng Việt
  - 처음에는 폰 언어를 따르고, 메인 화면의 🌐 언어 버튼으로 직접 바꿀 수 있습니다. 2개까지 골라서 같이 볼 수도 있어요.
- **방문자 통계 (웹)**: [GoatCounter](https://www.goatcounter.com)로 방문 수를 셉니다 (쿠키 없음). 메인 화면 맨 아래에 누적 방문 수 👀 표시
- **진동**: 모든 버튼과 게임 터치에 진동이 오고, 당첨·승리 때는 강하게 진동합니다.
- **화면 꺼짐 방지**: 게임 중에는 화면이 꺼지지 않습니다.
- 메인 로고나 "WOLF" 글자를 누르면 홈페이지(https://wolf.community)로 이동할지 묻는 창이 뜹니다.

## 🛠 기술 정보
- Kotlin + Jetpack Compose, Android 8.0(API 26) 이상
- 고정 서명키(`app/debug.keystore`)를 사용해서 새 버전을 덮어 설치할 수 있습니다.
- 빌드: GitHub Actions(`.github/workflows/main.yml`) 또는 Android Studio
- 웹 버전: `web/` (HTML/JavaScript, 빌드 과정 없음) → `.github/workflows/pages.yml`로 GitHub Pages에 배포
  - 문구는 앱의 `Strings.kt`에서 변환한 `web/i18n.js`를 씁니다.
- 문구는 `app/src/main/java/com/wolfgames/app/i18n/Strings.kt`에 6개 언어로 모여 있습니다.
  - 웹 문구 갱신: `python3 tools/gen_web_i18n.py`
  - 버전별 수정 내역은 `tools/changelog.py` 한 곳에 적고 `python3 tools/gen_changelog.py` → 앱(`Changelog.kt`)·웹(`web/changelog.js`)·설치 안내에 같이 반영
  - 설치 안내 문구는 `tools/manual_text.py`, 페이지·그림 갱신은 `python3 tools/build_manual.py`
- QR: 앱은 [ZXing](https://github.com/zxing/zxing) core, 웹은 [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator)(MIT) — 둘 다 폰 안에서 만듦
- 점검: APK를 만들 때마다 에뮬레이터에서 앱이 켜지는지 확인하고(꺼지면 릴리스 안 함), `.github/workflows/smoke.yml`(`tools/smoke.sh`)로 새 화면을 하나씩 열어 화면을 찍어 봅니다.
