# 🐺 울프 게임즈

술자리 게임 모음 안드로이드 앱

## 게임 목록
1. **주사위**
   - 주사위 굴리기: 여러 손가락 동시 터치, 2초 누르고 떼면 주사위 공개, 더블탭 초기화
   - 숫자 뒤집기 잭팟: 1~12 판, 두 눈과 합 중 하나 뒤집기, 마지막 숫자를 뒤집은 사람 승리
   - 5개 주사위: 2~4명, 동시에 굴림, 1은 아웃 / 6은 시계방향으로, 다 없어지면 승리
2. **악어이빨**: 20개 중 당첨 1개
3. **사다리게임**: 참가 인원(2~10) · 당첨 개수 지정
4. **돌림판**: 칸 수(2~20) · 당첨 개수 지정

## APK 받는 법
이 저장소에 파일이 올라가면 GitHub Actions가 자동으로 APK를 만들어
**Releases** 메뉴에 `WolfGames.apk`로 올려줍니다.
코드를 수정해서 다시 올릴 때마다 새 빌드가 만들어집니다.

## 기술 정보
- Kotlin + Jetpack Compose, minSdk 26 (Android 8.0 이상)
- 고정 서명키(`app/debug.keystore`) 사용 → 새 버전을 지우지 않고 덮어 설치 가능
- Android Studio로 열어서 직접 빌드도 가능
