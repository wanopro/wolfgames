## 1. Up/Down (카드)

1. **첫 카드 오픈**: 덱 맨 위 1장을 바닥에 오픈 (기준 카드)
2. **선택**: 도전자가 다음 카드를 예상
   - 일반 카드일 때 → **UP** 또는 **DOWN**
   - 기준 카드가 **A 또는 K**일 때 → **레드** 또는 **블랙**
3. **다음 카드 확인**: 도전자가 다음 카드를 뒤집음
   - **성공**: 다음 사람 차례, 방금 뒤집은 카드가 새 기준 카드
     - (옵션) 성공할 때마다 마셔야 하는 술의 양이 누적
   - **실패**: 도전자가 벌주, 게임 리셋
   - **같은 숫자**: 억까 → 원샷

미정(확인 필요) — 괄호는 Claude 기본안
- [ ] 카드 순서 A=1 낮음 … K=13 높음 (기본안: 맞음)
- [ ] 같은 숫자 원샷 후 리셋? 다음 사람? (기본안: 원샷 후 리셋)
- [ ] 조커 포함 여부·효과 (기본안: 조커 없이 52장)
- [ ] 누적 옵션: 성공마다 +1잔, 실패한 사람이 누적분 마심, 설정에서 켜고 끔, "누적 3잔" 표시 (기본안)
- [ ] 인원 2~8명 설정, "플레이어 n 차례" 표시 (기본안)
- [ ] 덱 소진 시 자동 셔플, 리셋 시 기준 카드 새로 1장 (기본안)

## 2. 789 (주사위)

- 주사위 2개, 터치하면 **튀어오르는 애니메이션**과 함께 굴러감
- 두 주사위 합의 **뒷자리**로 결과
  - **7** → 첨잔
  - **8** → 반샷 (반만 마시기)
  - **9** → 원샷 (한 번에 다 마시기)
  - **6** → 순서 역전 (옵션)
  - 나머지 → 다음 순서로
- 결과(첨잔 / 반만 마시기 / 한번에 다 마시기 / 순서 반대로)를 **화면에 크게 문자로** 표시

미정(확인 필요)
- [ ] 합 2~12라 사실상 합 6·7·8·9만 해당 (10·11·12는 뒷자리 0·1·2 → 넘어감) 이해 맞는지
- [ ] 인원 설정 + "플레이어 n 차례 →" 차례·방향 화살표 표시, 6이면 방향 반전 (기본안)
- [ ] 6 순서 역전은 설정에서 켜고 끔 (기본안)

## 3. 호치민 (카드)

- 최대 **4명** (화면 표시 제한)
- 카드 값: **A~10 적힌 숫자 (A=1), J·Q·K = 10**
- 세팅
  - 셔플 후 모든 플레이어에게 1장씩 **앞면 오픈** → 게임 끝까지 본인의 **고유 숫자**
  - 남은 덱(창고)에서 2장을 바닥에 오픈 (필드 카드 2더미)
- 진행 (1번 플레이어부터 시계 방향)
  1. 필드 2장 중 바꾸고 싶은 1장을 선택
  2. 창고에서 새 카드 1장을 뽑아 **선택한 카드 위에 겹쳐 오픈** (바닥은 항상 2더미)
  3. 두 더미 맨 위 카드 합의 **뒷자리** 확인 → 본인 개인 카드 숫자와 같은 플레이어가 **벌주**
     - 예: 7 + Q(10) = 17 → 뒷자리 7 → 개인 카드 7인 사람 독박 원샷

미정(확인 필요)
- [ ] 개인 카드 10·J·Q·K인 사람 → 뒷자리 **0**일 때 벌칙
- [ ] 같은 숫자 여러 명이면 모두 벌칙
- [ ] 시작 때 깐 2장의 합도 벌칙 확인? (기본안: 1번 플레이어 첫 턴부터)
- [ ] 끝나는 조건 없음, 덱 소진 시 (개인 카드·필드 맨 위 제외) 재셔플, "새 게임"으로 다시 배분 (기본안)
- [ ] 화면 배치: 폰 가운데 두고 마주 보게(5개 주사위처럼) vs 한 방향 (기본안: 각자 영역 + 가운데 필드 2장)

- 순위는 지금처럼 (먼저 물린 동물 = 1등, 순위가 따로 표시되니 이대로 OK), 끝나면 "1등: 🐑 양 · 꼴찌: 🐷 돼지"
- 순위가 엎치락뒤치락하는 달리기 방식은 그대로

## ⚡ 새 카테고리: 순발력게임 (2026-10-23 메모, 시안 `docs/samples/quick/`)

공통: **원형 화면 분할** — 화면 가운데를 중심으로 인원수만큼 **같은 넓이**로 둘러앉은 모양(P1 아래, 시계방향 P2·P3…), 각 영역 글자는 그 사람 쪽을 향해 회전. 가운데 원에 공용 표시(지정색·목표 초·방향). 2~8명 모두 같은 방식 (`split.js`의 `sectors()`).

### 1. ⚡ 반응속도 대결 (2~4명)
- "기다리세요..." (어두운 빨강) → 랜덤 시간 뒤 화면 전체 **초록**으로 바뀌는 순간 터치
- 각자 영역에 반응 시간 표시 (0.000초), **1등 👑 금색 테두리 / 꼴찌 💀 빨간 테두리**
- 초록 되기 전에 누르면 **🚫 부정출발** (꼴찌 처리) — 시안 기준, 확정 필요

### 2. 🎨 색 반응 대결 (2~4명)
- 가운데에 이번 판 **지정색** (판마다 랜덤: 빨강·주황·노랑·초록·파랑·보라)
- 분할 화면 전체가 같은 색으로 **0.1~0.5초마다 랜덤하게** 바뀜
- 지정색이 나오면 터치 → **못 누른 사람 = 걸림 💀** (시안: 지정색은 1.5초 유지, 다른 색일 때 누르면 "땡!" 걸림)
- 모두 눌렀으면 반응 시간 표시 + 등수, 1등·꼴찌 강조

### 3. ⏱️ 스탑워치 (2~4명)
- 목표 초 선택 → 가운데에 목표 초 표시, 3·2·1 뒤 시작 (시간은 안 보임)
- 속으로 세고 각자 터치 → 모두 끝나면 결과: **소수점 2자리**(5.06초)와 차이(+0.06초)
- 목표에 가장 가까운 사람 1등 👑, 가장 먼 사람 꼴찌 💀
